An advanced Computer Vision and Deep Learning engine developed in Python. It maps 21 articular hand nodes in real-time to accurately translate Mexican Sign Language (LSM) into text and voice. The model is **fully trained utilizing a robust dataset of over 40,000 images**, featuring a flexible Free Mode for real-time translation and a Gamified Learning Module for interactive practice.

## ✨ Features

* **Massive Deep Learning Model:** Fully trained neural network powered by TensorFlow and OpenCV, leveraging a custom dataset of 40,000+ images for high-precision gesture recognition.
* **Free Mode (Real-Time Translation):** Highly accurate, dynamic hand tracking that instantly classifies the complete A-Z alphabet and formal phrases into on-screen text.
* **Gamified Mini-Game Module:** An interactive, hangman-style spelling game where users practice physical sign language to progress, building fluency in a fun and engaging environment.
* **Voice Assistant Integration:** A built-in, offline Text-to-Speech (TTS) engine (pyttsx3) that instantly vocalizes detected signs with zero latency.
* **Fail-Safe Architecture:** A robust automated internal logging system and a modular codebase that cleanly separates the AI engine from the user interface.

## 🛠 Technologies Used

* **Core Language:** Python 3.x
* **Computer Vision:** OpenCV, MediaPipe
* **Machine Learning:** TensorFlow / Keras, NumPy, Pandas
* **Accessibility:** pyttsx3 (Text-to-Speech)
